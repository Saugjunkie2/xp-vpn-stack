TITLE: MyPal NSS Cert Import (cert9.db)
VERSION: v1.1
DATUM: 2026-01-20
STATUS: ACTIVE
PRIORITY: MUST
REQUIRES: B060, B200, B220, B230
INFLUENCES: B230, B240
OWNER-INTENT: MyPal vertraut interner Root-CA (NSS cert9.db), damit HTTPS auf SERVICE_WEB 10.77.0.3 (vpn.status/Blockpage) ohne Warnung funktioniert.
OWNER: Marco (Owner) + ChatGPT (Co-Architect)

NOTES:
- MyPal nutzt NSS (cert9.db) – Windows Zertifikatsspeicher reicht für diesen Browser nicht aus.
- Gilt nur für NSS-basierte Browser; IE/WinHTTP nutzen andere Stores und brauchen separate Behandlung.
- Import muss den richtigen Profilpfad treffen und verifiziert werden (Aufruf einer internen HTTPS-Seite ohne Warnung).
- Verifikation (SoT): HTTPS-Aufruf auf vpn.status (DNS Rewrite aus B200 -> SERVICE_WEB 10.77.0.3) muss ohne Warnung funktionieren.
- Blockpage-Pfad (B230): Bei geblockten Domains landet HTTPS ebenfalls auf SERVICE_WEB 10.77.0.3; Ziel ist „no warning“ für MyPal (SNI-fähig).
================================================================================

1) ZWECK
- Import CA in MyPal NSS DB (cert9.db) im Profil.

2) GRENZEN
- Windows cert store import reicht nicht.
- certutil needs supporting DLLs (portable NSS bundle).

3) ABHÄNGIGKEITEN
- Requires: B060, B200, B220, B230
- Influences: "no warning" HTTPS (B230), Setup Tool UX/Automatisierung (B240)

4) INPUTS
- Portable NSS tools bundle
- MyPal profile discovery logic
- Root-CA Zertifikat als Datei (Format klar definiert: PEM/DER), das in NSS importiert werden soll
- Verifikations-Target (SoT): vpn.status (via B200 Rewrite -> SERVICE_WEB 10.77.0.3)

5) OUTPUTS
- CA trusted in MyPal -> HTTPS MITM works.

6) MUST
- Bundle includes certutil + required libraries (portable NSS bundle; keine System-Install-Pflicht).
- Profile discovery robust:
  - findet den aktiven MyPal Profilpfad deterministisch (keine „zufällige“ Auswahl bei mehreren Profilen)
  - wenn mehrere Profile existieren: klare Regel (z.B. Default-Profil zuerst) + Logging/Report welches Profil gepatcht wurde
- Import idempotent:
  - prüft vor Import, ob die Root-CA bereits in cert9.db vorhanden ist (z.B. anhand Nickname/Fingerprint)
  - bei vorhandenem Eintrag: kein erneuter Import, kein DB-Churn
- Trust-Flags sind korrekt gesetzt (Root-CA als Trust Anchor, nicht nur „importiert aber untrusted“).
- Verifikation ist Pflicht (DoD):
  - nach Import muss HTTPS auf vpn.status (-> SERVICE_WEB 10.77.0.3) ohne Warnung funktionieren
  - Fehlschlag liefert klaren Failure-Reason (z.B. Profil falsch, CA falsch, Trust-Flags fehlen)
- Keine Secrets/PII:
  - keine Credentials/PSKs/Token in Logs/Reports; nur technische Diagnose (Profilpfad, Erfolg/Fehlercodes)

7) OPTIONAL
- Support multiple profiles.

8) FEHLERBILDER
- MyPal still warns -> wrong profile or import failed.

9) TESTS
- Negativtest: vor Import zeigt MyPal bei https://vpn.status eine Zertifikatswarnung (erwartet).
- Positivtest: nach Import öffnet MyPal https://vpn.status ohne Warnung (B200 Rewrite -> SERVICE_WEB 10.77.0.3).
- Blockpage-Pfad: nach Import öffnet MyPal eine geblockte Domain (B230/AdGuard Custom IP -> 10.77.0.3) ebenfalls ohne Warnung.
