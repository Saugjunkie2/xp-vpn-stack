NOTES:
- Setup-Tool ist Pflicht: es automatisiert XP/Vista VPN-Config, Registry-Fix, CA-Import und einen eindeutigen Connectivity-Test.
- Kein Handbuch-Marathon: der User soll nicht in Windows-Dialogen Einstellungen suchen müssen.
- Tool muss Prüfungen liefern (Tunnel up, DNS enforced -> SERVICE_DNS 10.77.0.1, /diag erreichbar -> SERVICE_WEB 10.77.0.3, NTP erreichbar -> SERVICE_NTP 10.77.0.4) und dabei keine Secrets im Klartext loggen (PSK/Passwörter nie in Logs/GUI ausgeben).
================================================================================

1) ZWECK
- Automatisiert alle kritischen client-side Schritte:
  - NAT-T reg fix
  - VPN connection creation
  - shortcuts (connect/disconnect/status)
  - time sync (pre & post)
  - CA import windows store + MyPal NSS
  - optional keepalive redial + diagnose button
- SoT Service-Targets (nicht frei editierbar im Tool):
  - DNS: 10.77.0.1, WEB/Portal/diag: 10.77.0.3, NTP: 10.77.0.4 (Unbound 10.77.0.2 ist server-only)

2) GRENZEN
- Tool muss idempotent sein (mehrfach laufen ok).
- Tool muss klar kommunizieren, wenn Adminrechte fehlen.

3) ABHÄNGIGKEITEN
- Requires: B060, B080, B150, B200, B210, B220, B250, B260, B270, docs/nft_service_ip_scopes.txt

4) INPUTS
- Server FQDN
- PSK
- Sub-account username/password per device
- CA cert files
- NSS bundle (certutil + dlls)
- Expected Service Targets (read-only): DNS 10.77.0.1, WEB/diag 10.77.0.3, NTP 10.77.0.4

5) OUTPUTS
- Functional VPN connection with minimal user interaction + Connectivity-Report (grün/rot) für Tunnel/DNS(/53 tcp+udp)/WEB(/diag)/NTP, ohne Secrets.

6) MUST
- Sets NAT-T registry key + reboot notice
- Creates VPN profile automatically
- Installs CA into Windows store
- Installs CA into MyPal NSS
- Implements time strategy (B260)
- Provides "Test" button (calls /diag)

7) OPTIONAL
- Redial loop script for unstable Wi-Fi users.

8) FEHLERBILDER
- Setup fails due to missing admin -> show message (inkl. Hinweis: Registry-Fix/Cert-Import brauchen Admin; ohne Admin keine Teilinstallation „halb fertig“).
- MyPal import fails -> show manual fallback instructions; /diag Test kann trotzdem HTTP/HTTPS Reachability zu SERVICE_WEB 10.77.0.3 prüfen (Warnung erwartbar, falls NSS Trust fehlt).

9) TESTS
- Clean XP VM run -> setup success -> connect works -> Validierung: /diag erreichbar auf SERVICE_WEB 10.77.0.3, DNS enforced zu 10.77.0.1 (udp+tcp 53), NTP reachable 10.77.0.4; Negativ: 10.77.0.2:53 (Unbound) nicht erreichbar als Client.
- Test muss DNS Enforcement validieren (tcp+udp 53): Erwartung Resolver = SERVICE_DNS 10.77.0.1 (auch wenn im Client 8.8.8.8 eingetragen ist -> DNAT via B210).
- Test muss NTP Target validieren: Erwartung NTP = SERVICE_NTP 10.77.0.4:123/udp (B260).
- Negative Expectation: Tool darf SERVICE_RESOLVER 10.77.0.2:53 nie als Client-Resolver konfigurieren; optionaler Negativtest dokumentiert, dass 10.77.0.2:53 für Clients nicht erreichbar sein muss (server-only).
